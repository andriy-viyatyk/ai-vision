A tiny task model an agent can read and drive

The page exposes the model, serializes its shape, mounts a loopback remote proxy, and resolves calls against that proxy exactly as a host would.

Run npm run build first. This page has no bundler and makes no fetch requests, so it also works when opened directly with file://.
